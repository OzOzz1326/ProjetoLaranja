# Sport In City
É um site de aluguel e reserva de quadras esportivas, onde um usuário pode tanto encontrar uma quadra para usar, quanto cadastrar uma nova quadra.
Os quatro tipos de esportes que tem no site são:
    - Futebol
    - Futvôlei
    - Beachtênis
    - Tênis
